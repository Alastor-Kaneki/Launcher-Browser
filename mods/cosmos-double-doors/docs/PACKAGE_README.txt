Cosmos Double Doors 1.0.0 - by Alastor Kaneki
Native mod for Pocket Cosmos (LeviLaunchroid fork), Android arm64-v8a.

Opens and closes paired doors and trapdoors together.

Install: Pocket Cosmos -> Mods -> Import -> choose cosmos-double-doors.levipack,
make sure the mod is enabled for your Minecraft 26.5x version, then launch.

Settings: config/config.json inside the installed mod folder (or the
launcher's mod settings screen). Restart Minecraft after changing them.

Logs: adb logcat -s "Cosmos Double Doors" Preloader

Full documentation, source and troubleshooting:
https://github.com/Alastor-Kaneki/Launcher-Browser/tree/ccr-8b3e4d78-c5pmyu/mods/cosmos-double-doors
